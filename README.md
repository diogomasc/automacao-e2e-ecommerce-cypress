# Automação E2E de e-commerce com Cypress

## Como executar

```bash
git clone https://github.com/diogomasc/automacao-e2e-ecommerce-cypress.git
cd automacao-e2e-ecommerce-cypress
npm i
npm run cy:open
```

## Organização do projeto

```text
.
├── cypress/
│   ├── e2e/              Testes de cadastro e produto
│   ├── fixtures/         Dados usados nos testes
│   └── support/          Funções auxiliares e configuração de suporte
├── cypress.config.js     Configuração do Cypress
└── package.json          Dependências e scripts
```
